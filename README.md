# Governança Continuum AI Systems

Centro de comando da Continuum. Esta pasta governa cultura, estratégia, tática e operação como um sistema único.
**Comece sempre pelo `CLAUDE.md`** — ele define que você opera como CEO da Continuum.

---

## Como usar

1. Abrir `CLAUDE.md` → assume o papel de CEO e as regras permanentes.
2. Classificar o pedido em um modo (`00-core/MODOS-DE-RESPOSTA.md`).
3. Carregar a skill dominante (`10-skills/…`).
4. Consultar o contexto necessário (`30-comercial`, `50-integracoes-dados`, etc.).
5. Entregar decisão + direção + ação + impacto.
