## 3. AS RÉGUAS QUE ESTE CORPO INSTITUI

Cada uma nasceu de um caso real e vale fora do caso.

| # | Régua | Nasceu em |
|---:|---|---|
| **1** | **Volume é a última camada.** Tráfego sobre fundação aberta acelera a recusa | as três contas |
| **2** | **A primeira alavanca não se constrói. Já está paga** | preço, base, prova e audiência paradas |
| **3** | **Construir e operar têm ordem de grandeza diferente.** É o que justifica setup + mensalidade | ciclo 1 a R$ 50/h × ciclo 2 a ≥ R$ 250/h |
| **4** | **O produto não pode se chamar pelo defeito do cliente** | descarte de "Mapa do Vazamento" |
| **5** | **Prova numérica de uma camada é a licença para dizer que ela não é o problema** | a bio e a peça de abertura |
| **6** | **Número de resultado é atribuível, logo contestável. Fato de carreira não é** | parecer da credencial |
| **7** | **Exceção declarada é legítima; exceção silenciosa não** | exceção de piso do Mapa |
| **8** | **Diagnóstico gratuito é o erro estrutural mais caro da casa** | o contrato que só coube porque a descoberta já tinha sido paga |
| **9** | **Amplitude é eixo de preço; profundidade não.** Vender "menos fundo" entrega meio diagnóstico. Vender "menos amplo" entrega um diagnóstico inteiro de um escopo menor | os dois Mapas |
| **10** | **Sugestão de execução não é execução.** A fronteira dita em voz alta é o que impede a expectativa errada | a devolutiva do Mapa |
