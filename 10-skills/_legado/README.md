# _legado — arquivo morto de skills

> **Nada aqui é fonte ativa. Nada aqui é carregado.** Esta pasta existe para que nenhuma decisão registrada se perca quando uma skill é substituída.

## A regra

1. Skill substituída **não some**: o conteúdo íntegro vem para cá, com um cabeçalho `[LEGADO · data]`.
2. O caminho antigo **não some**: ele vira um ponteiro curto que diz qual é a fonte ativa e onde está o conteúdo íntegro. Assim, referência velha em outro documento aterrissa na explicação, não em erro.
3. Arquivo daqui **nunca é carregado como skill**. Se um pedido cair num ponteiro, seguir para a skill que ele indica.
4. Consulta legítima daqui: descobrir **por que** uma regra existe, recuperar um exemplo removido, ou auditar o que mudou entre versões.

## Por que os exemplos daqui não voltam para as skills

As skills ativas são portáteis por decisão: sem nome de cliente, sem exemplo de copy real, sem caminho de arquivo deste repositório. Os arquivos desta pasta são anteriores a essa regra e contêm nome de cliente, exemplo real e caminho interno. **Eles servem de memória, não de fonte de exemplo.** Ao consultar, traduzir para o genérico antes de reaproveitar qualquer coisa.

## Nota sobre versionamento

Este repositório não tem histórico de git ativo (`.git` presente e vazio, verificado em 26/07/2026). Enquanto isso for verdade, **esta pasta é a única rede de segurança** contra sobrescrita. Qualquer artefato que for substituído passa por aqui antes.
