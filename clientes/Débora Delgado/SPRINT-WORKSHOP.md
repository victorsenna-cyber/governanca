# SPRINT-WORKSHOP.md — Lançamento "Carreira Alinhada"

**Meta:** sistema de aquisição operante (anúncio → landing → checkout → grupo →
workshop), sobre base firme, com aprovação humana em cada publicação.
**Início:** 29/06/2026 · **Modelo:** blocos D1–D7, executados no Cowork, bloco a bloco.
Ver `PROJECT.md` (visão), `CLAUDE.md` (como trabalhar), `OFERTA-CANONICA.md` (oferta).

## Objetivo (O)
Transformar material bruto + artefatos estratégicos num sistema de aquisição pronto
para rodar as primeiras turmas-piloto do workshop.

## Key Results (fim da sprint)
- **KR1** Funil ponta a ponta montado e testado (0 quebras no QA).
- **KR2** Landing + checkout publicáveis no Wix, sobre design system próprio.
- **KR3** 3–5 criativos + guia de produção para a Débora.
- **KR4** Estrutura de campanha Meta + plano de tracking (rascunho, sob aprovação).
- **KR5** Loop de iteração ativo (scheduled diário estruturado).
