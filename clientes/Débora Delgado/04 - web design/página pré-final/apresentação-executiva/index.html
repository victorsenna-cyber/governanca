A camada que mantém tudo coerente

Governança não é burocracia. É memória de decisão.

Quando o workshop evolui, a página, os criativos, o checkout e o painel precisam evoluir juntos. Por isso o projeto tem uma ordem clara de verdade.

Fonte → evidência → decisão → execução.

O sistema reduz retrabalho, impede que uma versão antiga volte ao ar e registra por que cada mudança foi feita.
