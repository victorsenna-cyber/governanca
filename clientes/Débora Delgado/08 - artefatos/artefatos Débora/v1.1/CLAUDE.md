Framework não é checklist de execução.

Framework é modelo de pensamento aplicado.

O arquivo pode conter checklists, scores, campos, matrizes e tabelas, desde que esses elementos sejam instrumentos do framework, não tarefas de sprint.

1. Manter os nomes físicos dos arquivos HTML.
Não renomear arquivos.

2. Alterar apenas títulos, textos visíveis, metadados internos visíveis e conteúdo semântico.

3. Preservar classes, IDs e JavaScript sempre que possível.

4. Não quebrar navegação, dark mode, score interativo, checklists ou campos.

5. Remover linguagem de projeto também do `<title>`, header, tags, navegação, rodapé e blocos de metadados.

6. Não basta remover a palavra Sprint do corpo principal.

7. Os arquivos devem parecer permanentes, não temporários.

8. A Débora deve sentir que está acessando uma infraestrutura própria de pensamento e decisão.
