# CHECKLIST DE AUDITORIA DE COPY — contra o perfil linguístico

Testa se um texto soa como a pessoa. Entregar **desvios + correção concreta**.

## Checklist das 7 dimensões
- [ ] **Tom** bate (acolhedor/direto, não-agressivo conforme perfil)?
- [ ] **Sistema representacional:** os verbos/sensações dominantes da pessoa aparecem?
- [ ] **Vocabulário-assinatura** presente (não substituído por sinônimos genéricos)?
- [ ] **Construção:** abre como ela abre (ex. história→padrão)? Pronome certo?
- [ ] **Metáforas** dela aproveitadas onde cabe?
- [ ] **Nada do que ela evita** (hype, jargão, guru, binário)?
- [ ] **Intensidade** na temperatura dela (não mais dramática nem mais fria)?

## Verificações objetivas (automatizáveis, ex. grep)
- Termos proibidos do perfil = **0**.
- Pronome dominante (ex. "a gente") **presente** nos trechos reflexivos.
- Verbos do sistema representacional dominante **presentes** (ex. visual: enxergar/clareza).
- Texto **abre com cena/história**, não com conceito.
- (Projeto Continuum) **zero travessões** — ver regra anti-AI-slop.

## Formato do laudo
1. Veredito em 1 linha + % de aderência estimada.
2. O que ACERTA (curto).
3. Desvios numerados, cada um com **correção concreta** (não só apontar).
4. O que NÃO mudar (evita regressão).
