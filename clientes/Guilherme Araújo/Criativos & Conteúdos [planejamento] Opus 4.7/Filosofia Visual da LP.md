  Filosofia Visual da LP

  Princípio fundador: o design não é estética sobreposta ao conteúdo — é uma extensão do conteúdo.

  A LP da Cartomancia Sistêmica não deve decorar o método; deve comportar-se como o método: estruturada,
  silenciosa, profunda, sem desperdício.

  Direção estética em uma frase: uma edição cuidada de um livro raro — não uma página de venda de curso online.

  Referência mental (apenas direcional): revistas culturais de tipografia clássica (Frieze, NYRB, Monocle),
  edições Penguin Classics, sites de pesquisa acadêmica sofisticados. Tudo o que opera por silêncio + tipografia
   + branco intencional.

  Anti-referência (aquilo que NÃO ser): templates de infoproduto (Hotmart-style), páginas de mentoria com selos
  brilhantes, sites com símbolos místicos, layouts com gradiente colorido, animações que celebram.

  O design comunica antes da copy: o ICP julga em 1 segundo se a página é confiável. A composição visual precisa
   ser suficientemente sofisticada para sinalizar "isto não é mais um curso comum" sem precisar dizer.

  Identidade Visual Estratégica

  Itálico: uso ritualístico, não decorativo. Sempre em Cormorant. Aplicado em 1–2 palavras por título, nunca em
  parágrafos longos.

  Letter-spacing:
  - Display (Cormorant): -0.02em (otimização ótica)
  - Body (Manrope): default
  - Eyebrow / caps: 0.18em (sinalização ritualística)

  Line-height:
  - Display: 1.04–1.1 (tensão, gravidade)
  - Body LG: 1.5
  - Body: 1.6–1.7 (legibilidade extendida)

  Sistema de Cores

  Paleta total — 7 valores apenas. Nenhum acréscimo.

  ┌────────────────┬───────────────────────┬───────────────────────────────────────────┐
  │     Token      │         Valor         │                  Função                   │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ bg-deep        │ #070C09               │ Fundo absoluto da página                  │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ bg-base        │ #0C1410               │ Fundo padrão de seções                    │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ bg-card        │ #111A14               │ Fundo elevado (cards, accordion)          │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ gold-primary   │ #C9A961               │ Ênfase / itálicos / CTA                   │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ gold-line      │ rgba(201,169,97,0.22) │ Linhas divisórias / contornos             │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ text-primary   │ #F2EBDA               │ Texto principal (creme — não branco puro) │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ text-secondary │ #B9AE94               │ Texto secundário / parágrafos             │
  ├────────────────┼───────────────────────┼───────────────────────────────────────────┤
  │ text-muted     │ #7A7468               │ Microcopy / metadados                     │
  └────────────────┴───────────────────────┴───────────────────────────────────────────┘

  Princípios de uso:

  1. Dourado nunca preenche grandes áreas. Só linhas (1px), texto pequeno, itálicos, CTA fill (limitado).
  2. Branco puro nunca é usado. Texto principal sempre creme (#F2EBDA) — reduz fadiga, aumenta sensação de
  leitura impressa.
  3. Gradientes não existem. Apenas tonalidades sólidas, com leve variação entre bg-base e bg-card.
  4. Verde, vermelho, azul não existem. Estados de erro/sucesso usam dourado vs. muted. Nada celebra com cor.

  Comportamento do dourado fosco:
  - Aparece como linha fina (1px) — organiza, não chama
  - Aparece como texto pequeno (eyebrow, CTA hover)
  - Aparece como itálico em títulos — ênfase emocional
  - Aparece como fundo de CTA primário — ÚNICO momento de preenchimento
  - Frequência ideal: 5–8 ocorrências visuais por dobra, máximo. Mais que isso = brilho excessivo = perda de
  gravidade.

  Comportamento do preto profundo:
  - É o estado padrão — não é "fundo", é "ambiente"
  - Variações sutis entre bg-deep, bg-base e bg-card criam camadas sem precisar de bordas
  - Nenhum elemento flutua "fora" do preto — tudo nasce dele

  Sistema de Espaçamento

  Princípio: o espaço vazio é um elemento de design — não ausência de design. Ele entrega RESPIRAÇÃO PSICOLÓGICA
   ao leitor.

  Escala (base 8px):

  ┌─────────┬──────────┬────────────────────────────┐
  │  Token  │  Valor   │            Uso             │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-1 │ 8px      │ Espaçamento interno mínimo │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-2 │ 16px     │ Entre microelementos       │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-3 │ 24px     │ Entre parágrafos curtos    │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-4 │ 32px     │ Entre subelementos         │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-5 │ 48px     │ Entre blocos               │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-6 │ 64px     │ Entre subseções            │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-7 │ 80px     │ Entre seções (mobile)      │
  ├─────────┼──────────┼────────────────────────────┤
  │ space-8 │ 96–130px │ Entre seções (desktop)     │
  └─────────┴──────────┴────────────────────────────┘

  Regras de aplicação:

  - Hero: padding top mínimo de 80px (mobile) / 130px (desktop) — não compete com navbar
  - Entre seções: sempre space-7 mobile / space-8 desktop — nunca menos
  - Dentro de seções: densidade controlada — máximo 3 níveis de hierarquia espacial
  - Reframe central: espaço duplo antes e depois (space-8 x2) — gravidade vem do isolamento
  - Margens laterais: clamp(20px, 5vw, 60px) — respeita borda em qualquer viewport

  ---
  Ritmo Visual da Página

  Princípio: a página tem RESPIRAÇÃO COMPOSTA — não densidade uniforme.

  Cadência:

  HERO         [DENSO]      conteúdo concentrado + respiração total ao redor
  RECONHECIMENTO [LEVE]     texto contido + muito espaço
  REFRAME      [ISOLADO]    1 frase + espaço dobrado = pausa total
  MÉTODO       [GRID DENSO] 3 cards + descrição + grid invisível
  PROVA        [GRID LEVE]  4 depoimentos + espaço entre cada
  GUILHERME    [DUAL]       2 colunas (mobile = stack) + bio respirada
  CURRÍCULO    [LISTA]      accordion fechado = denso mas comprimido
  OFERTA       [CARD ÚNICO] 1 elemento centralizado + tudo ao redor vazio
  FAQ          [LISTA]      linhas finas, expansível sob clique
  CTA FINAL    [ISOLADO]    1 botão + 1 microcopy + nada mais

  Picos e vales:
  - O reframe (seção 3) e a oferta (seção 8) são picos de isolamento — máximo espaço, mínimo elemento
  - Método, prova, currículo são vales de densidade — informação organizada, mas com respiração entre itens
  - Hero e CTA final são portais — entrada e saída, ambos com respiração total

  ---
  Hierarquia Visual

  Princípio: o olho deve sempre saber para onde ir. Hierarquia clara reduz fadiga cognitiva.

  Camadas (em ordem de prioridade visual):

  1. Eyebrow (caps dourada, pequena) → sinaliza tipo de seção (ritual de entrada)
  2. H2 grande (Cormorant display) → ideia central da seção
  3. Subtítulo body LG (Manrope) → expansão ou contextualização
  4. Corpo (Manrope body) → conteúdo principal
  5. Cards / itens (organizados em grid invisível) → unidades de informação
  6. Microcopy (muted) → contexto secundário

  Regras de visualização:
  - Apenas UM H1 por página (no hero)
  - H2 sempre precedido por eyebrow + divisor sutil (hairline dourada 48px de largura)
  - Nunca mais de 3 níveis de hierarquia em uma única seção
  - Nunca elementos "decorativos" que não pertencem à hierarquia (ícones gratuitos, ilustrações genéricas)

  Hero Section Visual Strategy

  Função visual: estabelecer o tom de toda a LP em 3 segundos.

  Composição (mobile-first):

  [NAVBAR DISCRETA - logo + 1 CTA tonal escuro]

  (80–130px respiro vertical)

  EYEBROW (dourada caps pequena)

  H1 — Cormorant 600 — italic em 1–2 palavras

  (24px gap)

  SUBHEAD — Manrope body LG, text-secondary

  (40px gap)

  CTA PRIMÁRIO (dourado fosco, full width mobile, fit-content desktop)

  MICROCOPY ABAIXO (text-muted, 13px)

  (80–130px respiro vertical)

  O que REMOVER do hero atual:
  - VSL embedado — desce para seção secundária (ou remove totalmente)
  - Lista de 3 bullets técnicos — não pertence ao hero
  - Proof bar (anos / alunos) abaixo do hero — não pertence à primeira dobra

  O hero é threshold — não vitrine. Carrega apenas o necessário para o leitor decidir continuar lendo.

  Desktop: layout em coluna única centralizada OU à esquerda com espaço vazio à direita (não split com VSL).
  Coluna única é mais cinematográfica para esta narrativa.

  Mobile-First Design Logic

  Princípio: a LP é mobile-first em fluxo, não em adaptação.

  Decisões estruturais para mobile (375–414px):

  ┌───────────────────────────────┬──────────────────────────────────────────────────────────────────┐
  │           Elemento            │                       Comportamento mobile                       │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Hero                          │ Stack vertical, sem VSL (ou VSL embaixo, separado, opcional)     │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ H1                            │ 36–40px máximo (não escalar mais)                                │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Grids 3 colunas               │ Stack vertical sempre                                            │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Grids 2 colunas               │ Stack vertical sempre                                            │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Padding lateral               │ 20px mínimo / 24px ideal                                         │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Padding vertical entre seções │ 64–80px (não menos)                                              │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ CTA                           │ Full-width (largura do container) com altura 56px+               │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Navbar                        │ Logo à esquerda + 1 CTA discreto à direita — sem menu hamburguer │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Imagens                       │ Aspect ratio fixo / lazy load / largura 100%                     │
  ├───────────────────────────────┼──────────────────────────────────────────────────────────────────┤
  │ Accordion currículo           │ Mantém — funciona melhor mobile que desktop                      │
  └───────────────────────────────┴──────────────────────────────────────────────────────────────────┘

  Decisões para tablet (768–1024px):

  - Hero permanece coluna única (não vira split)
  - Grids 3 colunas viram 2 colunas
  - Padding lateral aumenta para 40–60px

  Decisões para desktop (1024px+):

  - Max-width 1160px para container principal
  - Hero pode usar coluna única centralizada (recomendado) ou split com lado direito vazio elegante
  - Grids 3 colunas / 2 colunas
  - Padding entre seções aumenta para 130px

  O que NÃO fazer mobile:
  - Botões pequenos (<48px altura)
  - Texto menor que 16px no body
  - Floating CTAs persistentes
  - Modal de captura intrusivo
  - Carrossel horizontal de depoimentos (stack vertical sempre)

  Motion Philosophy

  Princípio: movimento serve à leitura. Movimento nunca é entretenimento.

  Tipos de movimento aceitáveis:

  ┌───────────────┬──────────────────────────────────────┬─────────────────────────────────────────────────┐
  │     Tipo      │             Quando usar              │                  Comportamento                  │
  ├───────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────┤
  │ Fade up       │ Reveal de elementos ao entrar        │ 0.85s, ease-out-expo, deslocamento Y 28px       │
  │               │ viewport                             │                                                 │
  ├───────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────┤
  │ Fade in       │ Background, hero inicial             │ 0.9s linear                                     │
  ├───────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────┤
  │ Hover lift    │ CTA primário                         │ Transform translateY(-2px) + sombra sutil       │
  │               │                                      │ dourada                                         │
  ├───────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────┤
  │ Color shift   │ Links / itens hover                  │ 200ms ease                                      │
  ├───────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────┤
  │ Accordion     │ FAQ / Currículo                      │ Max-height transition 250–300ms                 │
  │ open          │                                      │                                                 │
  └───────────────┴──────────────────────────────────────┴─────────────────────────────────────────────────┘

  Tipos de movimento PROIBIDOS:

  - Bounce / spring / elastic animations
  - Parallax de qualquer tipo
  - Scroll-driven scaling
  - Texto que aparece letra por letra
  - Counter-up animation ("0 → 800 alunos")
  - Slide horizontal sem trigger do usuário
  - Auto-play carousel
  - Pulse / glow infinito em CTAs
  - Cursor customizado / efeito de luz seguindo o mouse
  - Logo animado
  - Particles / star fields
  - Smoke / mist / fog effects
  - Rotação automática de elementos
  - Hover 3D em cards

  Princípio governante: o movimento deve ser invisível como design — o leitor deve sentir suavidade sem perceber
   a animação como evento. Se ela for "notada", está exagerada.

  Blueprint Visual Definitivo

  Síntese em 10 princípios não-negociáveis:

  1. Cormorant Garamond para gravidade. Manrope para clareza. Nenhuma outra fonte.
  2. 3 fundos escuros + 3 tons de texto + 1 dourado fosco. Nenhum extra.
  3. Dourado é raro — linhas, ênfase, CTA. Nunca preenche grandes áreas.
  4. Branco puro é proibido. Texto principal é creme.
  5. Cada dobra entrega 1 ideia + 1 emoção + espaço respirável.
  6. Reframe e oferta vivem em isolamento total — máximo de espaço vazio ao redor.
  7. Movimento serve à leitura — fade up é a única animação contínua.
  8. CTA é convite tipográfico, nunca botão de jogo.
  9. Mobile-first em fluxo, não em adaptação. Stack vertical sempre.
  10. Nenhum elemento de misticismo, infoproduto comum ou pressão visual.

  Aplicação do critério final:

  Antes de aprovar qualquer composição visual, perguntar:

  - Isto parece edição editorial cuidada — ou template de Hotmart?
  - Isto sinaliza método sério — ou curso de cartomante comum?
  - Esta dobra tem 1 ideia clara — ou 4 elementos concorrendo?
  - Este dourado serve — ou decora?
  - Esta animação ajuda leitura — ou chama atenção?

  Se a resposta tender para o segundo lado em qualquer pergunta, refazer.
