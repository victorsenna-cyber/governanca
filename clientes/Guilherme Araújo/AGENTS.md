# AGENTS.md

Este arquivo é a entrada curta e agnóstica de ferramenta para todo o repositório.

1. Leia `CLAUDE.md` antes de classificar ou executar qualquer solicitação.
2. Leia `STATUS.md`, as três últimas entradas de `DIARIO-DE-BORDO.md` e a task ativa.
3. Use `09 - operação/CATALOGO-ACERVO-LEGADO.md` para localizar o acervo atual; não presuma que a árvore futura já foi migrada.
4. Trate `00 - governança continuum/` como réplica imutável de capacidades gerais.
5. Não altere Governança, Débora, fontes brutas, históricos ou artefatos fora do contrato explícito.
6. Registre verificação e writeback conforme o kernel.

Em conflito, `CLAUDE.md` prevalece. Este arquivo não contém fatos do negócio.
