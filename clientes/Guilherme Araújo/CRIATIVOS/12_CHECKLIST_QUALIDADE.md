# 12_CHECKLIST_QUALIDADE.md
Versão: 1.0 | Criado: 2026-05-24

---

## Como usar

Aplicar antes de qualquer export (Estágio 5 do pipeline).

**Status por item:**
- OK — critério atendido
- REVISAR — precisa de ajuste antes de publicar
- BLOQUEIO — não publicar até corrigir

---

## Bloco 1 — Hook (primeiros 3s)

| # | Critério | Status |
|---|---|---|
| 1.1 | O hook aparece nos primeiros 2–3s do vídeo (ou no topo do estático/slide 1) | |
| 1.2 | O hook nomeia dor, situação ou reframe reconhecível pelo ICP | |
| 1.3 | O hook não começa com saudação ("Oi, tudo bem?", "Hoje vou falar sobre...") | |
| 1.4 | O hook não explica o produto nem faz pitch nos primeiros 3s | |
| 1.5 | O hook está em fonte/tamanho legível mesmo em miniatura | |
| 1.6 | O hook gera micro-tensão ou curiosidade — não é neutro nem genérico | |

---

## Bloco 2 — Thumbstop

| # | Critério | Status |
|---|---|---|
| 2.1 | O frame 0 (thumbnail) é distinto em relação ao feed padrão do nicho | |
| 2.2 | Há contraste visual suficiente para destacar o texto principal | |
| 2.3 | Não há logo, marca ou introdução nos primeiros 3s | |
| 2.4 | O criativo testado em silêncio ainda prende atenção pelo visual | |
| 2.5 | Para Reels câmera: expressão facial ou postura da pessoa no frame 0 é intencional | |

---

## Bloco 3 — Retenção e narrativa

| # | Critério | Status |
|---|---|---|
| 3.1 | A estrutura narrativa segue um dos modelos definidos (04/05/06_md correspondente) | |
| 3.2 | A progressão emocional está completa: atenção → identificação → nomeação da dor | |
| 3.3 | Não há salto de etapa (ex: ir direto ao produto sem completar identificação) | |
| 3.4 | Cada segmento do vídeo tem função clara (não há trecho neutro ou de preenchimento) | |
| 3.5 | O ritmo de corte é adequado ao funil: mais dinâmico em TOFU, mais pausado em BOFU | |
| 3.6 | Para Carrossel: cada slide prepara o próximo — não há slide isolado sem conexão | |
| 3.7 | Para Carrossel: a progressão de slides segue arco completo (problema → expansão → CTA) | |

---

## Bloco 4 — Clareza e alinhamento emocional

| # | Critério | Status |
|---|---|---|
| 4.1 | O estado emocional ativado no criativo é compatível com o estado esperado na LP | |
| 4.2 | O hook promete algo que o corpo do criativo entrega | |
| 4.3 | Nenhuma afirmação direta sobre o leitor ("você está ansiosa", "você não consegue") | |
| 4.4 | Linguagem contextual usada (para quem..., para profissionais que...) | |
| 4.5 | Nenhuma promessa inflada (cura garantida, resultado financeiro garantido) | |
| 4.6 | O criativo pode ser entendido por alguém que nunca ouviu falar do produto | |

---

## Bloco 5 — CTA

| # | Critério | Status |
|---|---|---|
| 5.1 | Há um CTA claro no criativo (texto falado, on-screen ou slide final) | |
| 5.2 | O CTA aparece após completar a condução — não antes | |
| 5.3 | O tom do CTA é de convite, não de pressão | |
| 5.4 | O CTA nomeia o produto ou o próximo passo — não usa "saiba mais" genérico | |
| 5.5 | Não há urgência artificial ("últimas vagas", "só hoje") em criativos TOFU | |
| 5.6 | Para BOFU: o CTA inclui preço e garantia (7 dias, R$97, acesso imediato) | |
| 5.7 | O CTA está posicionado conforme o formato (últimos 10–15s em Reels, terço inferior em Estático, slide final dedicado em Carrossel) | |

---

## Bloco 6 — Texto on-screen

| # | Critério | Status |
|---|---|---|
| 6.1 | Texto on-screen complementa — não repete palavra por palavra o áudio | |
| 6.2 | Tamanho de fonte legível em tela de celular sem ampliar | |
| 6.3 | Contraste texto/fundo suficiente (não cinza claro sobre fundo branco) | |
| 6.4 | Máximo de 1–2 linhas por frame — não paragrafos longos | |
| 6.5 | Não há texto sobreposto ao rosto da pessoa (em Reels câmera) | |
| 6.6 | Fonte consistente com padrão visual do 14_PADRAO_VISUAL.md | |

---

## Bloco 7 — Áudio

| # | Critério | Status |
|---|---|---|
| 7.1 | Voz narrada está limpa — sem eco, ruído de ambiente ou compressão excessiva | |
| 7.2 | Volume da voz é dominante em relação à música de fundo | |
| 7.3 | Música de fundo não tem letra (evitar distração ou conflito de mensagem) | |
| 7.4 | Não há cortes abruptos de áudio sem tratamento de transição | |
| 7.5 | Criativo testado em mudo: funciona visualmente sem depender do áudio | |

---

## Bloco 8 — Edição técnica

| # | Critério | Status |
|---|---|---|
| 8.1 | Vídeo sem tela preta ou estática nos primeiros e últimos frames | |
| 8.2 | Cortes alinhados ao ritmo da fala (não corta no meio de palavra ou sílaba) | |
| 8.3 | Transições não usam efeito chamativo ou animação agressiva | |
| 8.4 | Resolução mínima atendida (1080x1920 para Reels, 1080x1080 para feed/estático) | |
| 8.5 | Duração dentro do range do formato: 45–90s TOFU Reels / 30–60s MOFU | |
| 8.6 | Arquivo exportado sem artefato de compressão visível | |

---

## Bloco 9 — Estética e identidade visual

| # | Critério | Status |
|---|---|---|
| 9.1 | Paleta de cores segue padrão do 14_PADRAO_VISUAL.md | |
| 9.2 | Fundo não é genérico ou poluído (para texto animado: fundo neutro ou escuro limpo) | |
| 9.3 | Não há logotipo ou marca proeminente que sinalize propaganda desde o início | |
| 9.4 | Iluminação do rosto adequada (sem sombra pesada, sem superexposição) | |
| 9.5 | Enquadramento correto: rosto centralizado, olhos no terço superior do frame | |
| 9.6 | Para Carrossel: identidade visual consistente entre todos os slides | |

---

## Bloco 10 — Transição para LP

| # | Critério | Status |
|---|---|---|
| 10.1 | Estado emocional ao final do criativo é compatível com o H1 atual da LP | |
| 10.2 | Se H1 da LP estiver desalinhado: registrar como risco antes de publicar | |
| 10.3 | Promessa do criativo tem correspondência na LP (não cria atrito de expectativa) | |
| 10.4 | URL de destino do anúncio aponta para a LP correta (não para perfil Instagram) | |
| 10.5 | Pixel PageView está ativo na LP (verificar antes de publicar) | |

## Resumo de bloqueios críticos

Não publicar se qualquer um destes estiver como BLOQUEIO:

| Critério de bloqueio | Referência |
|---|---|
| Hook ausente ou após 3s | 1.1 |
| CTA ausente | 5.1 |
| URL de destino não verificada | 10.4 |
| Pixel não confirmado na LP | 10.5 |
| Afirmação direta sobre o leitor (compliance) | 4.3 |
| Promessa inflada (compliance) | 4.5 |
| Texto ilegível em miniatura | 1.5 / 6.2 |
