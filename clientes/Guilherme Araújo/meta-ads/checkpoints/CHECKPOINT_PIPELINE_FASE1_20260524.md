## O que cada arquivo cobre

### 11_PIPELINE_PRODUCAO.md
Pipeline de 9 estágios sequenciais para cada criativo:

```
Briefing → Pré-produção → Gravação/Criação → Edição → QA → Export → Publicação → Monitoramento → Iteração
```

Inclui:
- Input e output de cada estágio
- Checkpoints obrigatórios com critério de passagem
- Nomenclatura de arquivos por formato
- Especificações técnicas de export (resolução, fps, formato)
- Rotina de monitoramento dias 1–3, 3–7 e decisão no dia 7
- Condições de iteração (quando e o que iterar)

### 12_CHECKLIST_QUALIDADE.md
56 critérios em 10 blocos aplicados antes de qualquer export:

| Bloco | Foco |
|---|---|
| 1 — Hook | Aparição, conteúdo, formato nos primeiros 3s |
| 2 — Thumbstop | Frame 0, contraste, silêncio, expressão |
| 3 — Retenção e narrativa | Estrutura, progressão emocional, ritmo |
| 4 — Clareza e alinhamento emocional | Estado ICP, linguagem, compliance |
| 5 — CTA | Presença, posição, tom, conteúdo |
| 6 — Texto on-screen | Legibilidade, posição, fonte |
| 7 — Áudio | Voz, música, cortes |
| 8 — Edição técnica | Cortes, resolução, duração |
| 9 — Estética e identidade | Paleta, iluminação, enquadramento |
| 10 — Transição para LP | Alinhamento emocional, URL, pixel |

**7 bloqueios críticos** — impedem publicação se não resolvidos:
1. Hook ausente ou após 3s
2. CTA ausente
3. URL de destino não verificada
4. Pixel não confirmado na LP
5. Afirmação direta sobre o leitor (compliance)
6. Promessa inflada (compliance)
7. Texto ilegível em miniatura
