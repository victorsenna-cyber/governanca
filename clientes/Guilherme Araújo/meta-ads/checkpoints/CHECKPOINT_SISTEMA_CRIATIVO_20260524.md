## Lógica organizacional

O sistema foi estruturado em camadas:

```
00 → Fundação estratégica (diagnóstico, arquitetura, ICP)
01 → Pilares narrativos (o que construir em tudo)
02 → Ângulos (o que explorar em cada criativo)
03 → Hooks (como abrir cada criativo)
04–06 → Execução por formato (como construir cada tipo)
07 → Testes (como aprender com os dados)
08 → CTA e condução (como fechar o loop)
09 → Otimização (como evoluir)
10 → Backlog (o que produzir e quando)
```

Cada camada alimenta a próxima. O backlog (10) é a saída operacional de todas as camadas anteriores.
