## O que cada arquivo cobre

### 13_WORKFLOW_ITERACAO.md

Sistema completo de decisão pós-dado:

| Decisão | Critério principal |
|---|---|
| MANTER | CTR >2%, LPV >40%, frequência <2,5, sem fadiga |
| ITERAR | CTR <2% após 5 dias / thumbstop fraco / CTA sem clique |
| PAUSAR | CTR <1% com múltiplos hooks / R$100+ sem LPV qualificada |
| NOVA VERSÃO | Hook testado e reprovado — manter ângulo, trocar abertura |

Inclui:
- Tabela dado → diagnóstico → hipótese → iteração (6 cenários)
- Rotina pós-teste de 4 passos (coletar / diagnosticar / decidir / registrar)
- Sistema de versionamento: CR-001_v1, CR-001_v2, etc.
- Log de aprendizados com formato de registro padronizado
- Cadência de iteração (dias 1–3 / 3–5 / 7 / pós-iteração)
- 7 erros a evitar ao iterar
