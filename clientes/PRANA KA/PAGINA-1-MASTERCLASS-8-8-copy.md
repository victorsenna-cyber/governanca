## ESTRUTURA DE LOTE — pronta e INATIVA (acende só se a Prana optar)

> Replicada do mecanismo validado da Débora (`Débora Delgado/04 - web design/.../index.html`). Hoje a página opera em **modo preço único R$ 88**. Se a Prana quiser lotes por data, basta preencher a config abaixo e ativar o bloco de timeline — o preço, a data-fim e a URL do checkout trocam sozinhos conforme o dia.

**Como funciona (padrão Débora):**
- `LOTES` guarda preço + URL de checkout por lote.
- `currentLote()` decide o lote vigente comparando a data de hoje com as datas-fim.
- A UI marca o lote vigente, esconde os encerrados, e o botão aponta para a URL certa automaticamente.

**Config a preencher SE ativar lotes (exemplo — números a definir com a Prana):**

```js
// MODO LOTE — deixar comentado enquanto for preço único.
// Para ativar: descomentar, preencher datas/preços/URLs e trocar o bloco de oferta pela timeline.
var LOTE1_FIM = '2026-08-XX';   // fim do 1º lote
var LOTE2_FIM = '2026-08-XX';   // fim do 2º lote (se houver)
var LOTES = {
  1: { price: 'R$ 88',  url: '{CHECKOUT_LOTE_1}' },   // valor atual vira o lote 1
  2: { price: 'R$ XXX', url: '{CHECKOUT_LOTE_2}' },
  3: { price: 'R$ XXX', url: '{CHECKOUT_LOTE_3}' }
};
function endOfDay(iso){ return new Date(iso+'T23:59:59'); }
function currentLote(){
  var now = new Date();
  if (now <= endOfDay(LOTE1_FIM)) return 1;
  if (now <= endOfDay(LOTE2_FIM)) return 2;
  return 3;
}
// resto do controlador (aplica classe is-vigente/is-encerrado, troca preço e href) = igual ao index da Débora.
```

**Regra do método:** escassez só real. Enquanto for preço único, **não** exibir contador nem "lote acabando". O bloco de timeline fica no HTML pronto, porém oculto (`hidden`), até a decisão dela.
